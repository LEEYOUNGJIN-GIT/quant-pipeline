# 최종 보고서: 이종 에이전트 다시장 퀀트 연구 파이프라인

작성일 2026-10-21. 이 문서는 서술적 결과를 기록한다. 전략의 유효성이나 수익성을 주장하지 않는다. 세금은 0으로 둔 자리표시자(Tax is a zero placeholder)이고, 모든 순수익 수치는 실거래에 맞춘 값이 아니다(not production-realistic).

## 1. 한눈에 보기

- **무엇을 만들었나.** 한국(KRX)과 미국(NYSE) 자산 9종목을 원화 기준으로 월 1회 배분하는 규칙 기반 전략과, 그 전략을 시간 누수 없이 평가하는 연구 파이프라인.
- **무엇을 알아냈나.** 단순 동일가중 월 리밸런싱과 같은 조건에서 비교했을 때, 전략이 낫다는 증거를 두 구간 모두에서 얻지 못했다. 동시에 낫지 않다고 단정할 증거도 없다.
- **무엇이 가장 단단한가.** 전략 결과가 아니라 평가 체계다. 이 체계가 회계 결함 1건과 솔버 설정 경계 문제 1건을 실제로 찾아냈고, 결함이 있던 첫 결과는 수정 후 크게 달라졌다.
- **무엇을 하지 않았나.** 봉인된 최종 홀드아웃은 열지 않았다(OQ-060). 따라서 세 번째 독립 표본은 없다.

## 2. 전략

롱온리, 원화 기준. 월 첫 거래일에 판단하고 주문은 다음 체결 가능한 종가에 낸다(판단 후 15분 지연, 한 걸음 늦은 체결).

| 구분 | 내용 |
|---|---|
| 대상(9종목) | 삼성전자(005930.KS), SK하이닉스(000660.KS), 현대차(005380.KS), 네이버(035420.KS), SPY, IEF, TLT, GLD, EEM |
| 제약 | 종목당 최대 30%, 현금 최소 5%, 월 편도 턴오버 35%, 미국 자산(환율) 노출 최대 50% |
| 에이전트 4종 | 추세(5·20·60·120일 수익률), 평균회귀(PCA 공통요인 제거 후 잔차 z), 방어(하락변동·요인 의존·낙폭이 작은 종목), 분산(최소분산) |
| 국면 | HMM 3상태의 필터링 확률(미래 정보를 쓰지 않는 방식). 국면별 에이전트 가중을 게이트로 섞는다 |
| 위험 방어 | 고위험 확률, 시장 낙폭, 공통요인 쏠림, 유동성 신호가 커지면 총 위험자산 비중을 줄이고 현금을 늘린다 |
| 최적화 | 목표 배분과의 거리, 포트폴리오 위험, 거래비용을 함께 최소화(OSQP) |
| 비교 기준 | `equal_weight_periodic`: 9종목 동일 비중을 같은 시점·같은 체결·같은 비용·같은 턴오버 한도로 매월 맞춘다 |

확정된 설정(real5, 선택된 trial `sha256:c054d3415dec…`): 추세 가중 [0.2, 0.3, 0.3, 0.2], 평균회귀 진입 z=1.5, PCA 요인 2개, 위험 회피 2.0, 비용 계수 0.5, 추적 계수 0.5, 방어 감마 1.0, 3상태 균형형 게이트. 파일: `docs/frozen_selection/real5/final_selection.json`(PR #11 병합 후).

## 3. 방법

- 중첩 워크포워드 평가: 안쪽에서 설정을 고르고 바깥에서 평가하며, 퍼지와 엠바고로 겹침을 막는다.
- 모든 적합(PCA, 공분산, HMM)은 각 판단 시점까지의 관측만 쓴다. 이 성질은 합성 데이터 테스트로 확인했다(미래 데이터를 바꿔도 이전 결과가 변하지 않음).
- 불확실성: 정상 블록 부트스트랩 95% 구간. 다중 시도(trial) 경고.
- 최종 홀드아웃은 봉인하고 사람만 열 수 있게 했다.
- 사전 등록: 전방 검증의 구간, 비교 기준, 판정 규칙은 해당 데이터를 수집하기 전에 OQ-056에 고정했다. 결과를 보기 전에 한 변경 1건(시작일 2025-01-02에서 2025-04-23)은 사유와 함께 기록했다.

## 4. 결과

| 구간 | 지표 | 전략 | 동일가중 |
|---|---|---|---|
| 사전 구간(선택에 사용) | 위험무이자 초과 연율 Sharpe [95% 구간] | 0.253 [-0.525, 1.053] | 0.671 [-0.240, 1.644] |
| 전방 2025-04-23~2026-09-30 (362구간) | 순초과 Sharpe [95% 구간] | 1.46 [-0.31, 3.04] | 1.92 [0.06, 3.98] |
| 같은 전방 구간 | 차이(전략-동일가중) [95% 구간] | -0.46 [-1.71, 0.54] | |
| 같은 전방 구간 | 총수익률 | 15.6% | 91.2% |
| 같은 전방 구간 | 최대 낙폭 | 3.5% | 22.2% |

판정 규칙은 차이의 95% 구간만으로 정한다. 구간이 0을 포함하면 증거 없음(`no_evidence`)이다. 두 구간 모두 전략의 점추정이 동일가중보다 낮고, 모든 구간이 0을 포함한다.

해석상의 주의:

- 증거 없음은 효과 없음이 아니다. 전방 구간은 약 1.4년이며 연율 Sharpe의 표준오차는 0.8~1 수준(근사)이다.
- 전략의 낮은 수익과 낮은 낙폭은 위험자산 비중을 줄이는 설계와 부합한다. 같은 기간 동일가중의 큰 수익이 상승장 노출 때문인지는 요인별로 분해하지 않았다.
- 전방 구간은 선택에 쓰이지 않았지만, 이 결과를 본 뒤 같은 데이터에서 설정을 다시 맞추면 선택 편향이 생긴다. 하지 않는다.

## 5. 이 과정에서 찾아낸 결함과 데이터 문제

| 항목 | 내용 | 영향 |
|---|---|---|
| OQ-057 | 원장이 KRW 종목의 배당에도 USD/KRW 환율을 곱했다. 고정 시나리오에 KRW 배당이 없어 테스트가 놓쳤다 | 전략 1.356에서 0.253으로, 동일가중 1.471에서 0.671로 달라졌다. 이전 수치(real3)는 인용하지 않는다 |
| OQ-058 | 솔버 재시도 정확도(1e-8)가 제약 허용오차(1e-8)와 같아 경계에서 거부되어 실행이 중단됐다 | 재시도 정밀도를 1e-9로 한 단계 높였다. 허용오차는 그대로 |
| 데이터 | Yahoo의 KRW=X에 2025-04-18과 2025-04-21 일봉이 빠져 있다. 환율이 117시간 지난 값이 되어 72시간 한도 게이트를 넘는다 | 한도는 풀지 않았다. 전방 시작일을 2025-04-23으로 옮기고 스냅샷은 `keep_on_gate_failure`로 보존했다 |
| 평가 오류 | 첫 전방 검증 도구가 전체 이력 구간을 채점했다(2,952구간) | 전방 블록 구간만 채점하도록 고치고 회귀 테스트를 추가했다. 그 실행 결과는 쓰지 않는다 |

## 6. 한계

- 표본: 전방 약 1.4년, 사전 구간 약 10년 중 일부, 9종목, 단일 시장군. 선택된 설정은 1개이고 전방 경로도 1개다.
- 세금은 0 자리표시자이고 거래비용은 모델 값이다.
- 최종 홀드아웃은 열지 않았다(약 1.3년 표본). real5 개봉은 아티팩트 만료(약 2026-11-01/02) 이후 불가능하다.
- 데이터 제공자(Yahoo, ECOS, FRED) 약관은 사용자가 확인해야 한다. 저장소는 공개이고 제공자 데이터는 재배포할 수 없으므로 실데이터 결과물은 암호화 아티팩트로만 보관했다.
- 사전 구간과 전방 구간은 real5 결과를 본 뒤에는 새 설계에 대해 깨끗하지 않다.

## 7. 결론

1. 이 전략을 실투자 근거로 삼을 증거는 얻지 못했다.
2. 단순 동일가중 월 리밸런싱은 같은 조건에서 강한 기준선이었다. 새 전략은 이 기준선을 넘는다는 증거를 먼저 보여야 한다.
3. 전략이 위험을 줄이는 쪽으로 움직였다(낙폭 3.5% 대 22.2%). 목표가 낙폭 제한이라면 Sharpe가 아닌 다른 기준으로, 새로 사전 등록해 평가해야 한다.
4. 평가 체계는 작동했다. 결함 수정 전 결과로 판단했다면 잘못된 결정이었을 것이다.
